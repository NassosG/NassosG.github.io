# limur.ai

Source for [limur.ai](https://limur.ai), the personal site of Nassos Galiopoulos. Less is more.

The site lives in [`site/`](site/) and is built with Astro. Every push to `master` deploys it to
GitHub Pages through [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

To post a paper or a thought, see [`site/README.md`](site/README.md).
